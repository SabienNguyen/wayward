# Chess Dojo

A single-page chess game for learning. Play friends online, play Claude, or play the computer at six levels, up to a strong engine, with a Claude tutor, step-through lessons and tactics puzzles. It's the chess counterpart of `shogi/` (Shogi Dojo) and shares its structure.

It is independent of the Wayward app: nothing here is imported by `src/` or built by Vite.

Published as a claude.ai artifact: <https://claude.ai/artifact/UVRzCWTu8MgWmeoZy6cVYB>

## Layout

| Path | What it is |
|---|---|
| `index.html` | The built page. Generated by `build.py`; don't edit by hand. |
| `src/engine.js` | Rules engine (castling, en passant, promotion, all draw rules), FEN, SAN/UCI notation, alpha-beta search with quiescence and piece-square tables. |
| `src/brain.js` | Brain, the strong engine behind Expert, Master and Grandmaster: typed-array board, Zobrist hashing, transposition table, iterative deepening on a time budget, PVS, null-move pruning, late-move reductions, killer and history ordering, and a tapered evaluation. It runs in a Web Worker. |
| `src/app.js` | The page: board UI, game modes, online lobby, Claude player, tutor, lessons, puzzles, progress. |
| `src/shell.html`, `src/style.css` | Page markup and styles, with `/*@@NAME@@*/` slots that `build.py` fills. |
| `curriculum/` | Lessons and puzzles, plus the scripts that verify them. |
| `tests/` | Perft and notation tests, and a Playwright browser test with mocked artifact capabilities. |

## Commands

Run from this directory:

```bash
python3 build.py          # rebuild index.html
bash tests/run.sh         # build + engine, curriculum and browser tests
```

`tests/brain.test.js` checks Brain the same way, one ply deeper, and cross-checks its legal moves against the reference engine in random games. `node tests/match.js <games> <brainMs> <oldDepth> [brainMs2]` plays Brain against the reference engine, or against Brain at another time limit.

## How the page uses claude.ai

The page runs as a claude.ai artifact and declares three runtime capabilities. Each one is optional: when it's missing, that feature degrades and the rest of the page keeps working.

- `db`: online games live in the `games` collection. Each game document holds the `white`/`black` seats (a viewer id or `"claude"`), the move list in UCI notation, its status and its result. Every viewer replays the moves through the engine. Each player's progress is stored privately at `data/users/<id>/stats`.
- `user`: identifies seats and shows player names.
- `sample`: powers the tutor, and Claude as an opponent. Claude is given the legal moves and the engine's top candidates, and its reply is checked against the legal list.

## Curriculum

- `curriculum/lessons.json`: 14 lessons, each with a start position, a line in UCI notation and per-move notes. They cover piece movement, special moves, four openings (Italian, Ruy Lopez, Queen's Gambit, Sicilian), forks, pins, skewers, discovered attacks, back-rank mate, basic mates, and the opposition. `check_lessons.js` replays each line and checks what each lesson claims, such as forks, mates and double check.
- `curriculum/puzzles.json`: 30 puzzles (10 mate-in-1, 10 mate-in-2, 10 win-material), harvested from engine games by `harvest.js`. `verify_puzzles.js` re-proves each one from its FEN with its own solver: a unique first move, every defence mated, or a material margin that holds at depth 3 and 4.
